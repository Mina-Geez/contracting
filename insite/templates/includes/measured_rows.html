That makes every other interpolation a hole: an item name of `` reached the printed page and ran, and an item name is plain text that loses nothing by being escaped. #} {% for row in rows %} {% endfor %}

{#- The measurement sentence is built from the boxes the line's RULE actually reads (recorded in custom_measurement_inputs), not from a fixed list of the shipped five.
